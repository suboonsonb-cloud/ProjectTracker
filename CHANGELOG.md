# Initiatives Tracker Desk — source changelog

Each update lists the files changed. After editing, run `python build.py` (→ `dist/SGA_Tracker_Desk.html`).
`js/13-studio-embed.js` is generated by build.py from `studio/Swimlane_Studio.html` — never edit it by hand.

## 2026-10-27 (r26) — Projects Summary: E2E tree, RAIDD column, status → tasks

|---|---|

## 2026-10-27 (r18) — many people, one workbook: merge on save · PowerPoint → E2E flow

| File | What changed |
|---|---|
| `js/03d-merge.js` | **New file.** Smart merge when the file was saved by someone else after you opened it: reloads the newer file, re-applies only YOUR changed cells, keeps theirs; same field changed by both → one "clash" dialog (theirs / mine per field, all theirs / all mine); rows you added go to a free row if the other person used the same row; your new project / task / benefit IDs are renumbered if they clash (child tasks, benefits, RAIDD, actuals follow). Shows who else saved (from the Activity log). Every minute the Desk checks the file: nothing unsaved → quietly loads the newer version; unsaved → tells you Save will merge. |
| `js/03-io.js` | Save merges automatically (no Merge / Overwrite question); "file changed while writing" (InvalidStateError) → merge and retry; after-save check no longer calls another person's later save "replaced" when your changes are still in it; sign-in kept through a merge. |
