# SG&A Tracker Desk — source changelog

Each update lists the files changed. After editing, run `python build.py` (→ `dist/SGA_Tracker_Desk.html`).
`js/13-studio-embed.js` is generated by build.py from `studio/Swimlane_Studio.html` — never edit it by hand.

## 2026-10-27 (r15) — simpler activity log

| File | What changed |
|---|---|
| `js/10b-activity.js` | Activity log shows **one line per action**: When · Who · Area · "Created / Updated / Deleted *what*" + a short "field: old → new" summary; "▸ all changes" opens every field. Task edits are grouped per project. A deleted user whose row is re-used for a new person is logged as Delete + Create. Only important edits are logged: input fields of Projects, Tasks, Benefits, RAIDD, Actuals, Settings, plus Users and E2E flows (no IDs, calculated cells or system sheets). |
