# Initiatives Tracker Desk — source changelog

Each update lists the files changed. After editing, run `python build.py` (→ `dist/SGA_Tracker_Desk.html`).
`js/13-studio-embed.js` is generated by build.py from `studio/Swimlane_Studio.html` — never edit it by hand.

## r59 — 2026-11-11
- Unsaved-changes prompt (leaving a page) now has three buttons: Don't save (discards every unsaved edit and reloads the last saved data), Not now, Save to database. Settings → Discard all uses the same discardChanges().

## r58 — 2026-11-11
- Projects → Old view rebuilt as the 2T Club Project_Data layout (new js/12c-projects-2t.js): Project ID, Name, Objective, Category, Process, Division, Function, App 1–3, Lead, Members, Phase, Time Line, Start, End, Days, Plan %, Progress, Status, Done, Will do, Issue, Frequency, Usage As-is / To-be, Saving time, Saving hours, Est. cost saving, FTE, Priority, Requester, Remark.
- Every cell edits the tracker in place: dropdowns linked to tracker lists (Category = Initiative, Process, Division = CF, Priority, Target quarter, status override); Phase = the project's stages (picking one sets earlier stages 100 %, later 0 %); App 1–3 split/join Technology / Tools; benefit columns read/write the time-saving benefit line (created if missing).
- Tracker-only detail kept in an extra group (Programme, BU, WS leader, Forecast end, Tasks, RAIDD, Value, Realised, E2E flow, Updated) — toggle "Show tracker detail".
- Spreadsheet look: colour-banded column groups, sticky header, frozen ID + name, borderless cells that highlight on hover/focus.

## r57 — 2026-11-11
- Projects page view switch renamed: New view · V1 view (was Old view) · Old view (was Table).
- Project details panel → Tasks: one card per stage/task with Plan and Actual/forecast bars (dark = % done, red when late, today line), a % done slider plus 0/50/100 quick buttons that save right away, status and Late? on each card.
- Project details panel → RAIDD filled in place (no second pop-up): edit open items inline (type, attached to, description, due, status, priority, impact, re-plan fields, remark), add new items, closed items folded away. Late? on a task opens the pre-filled form here.
- RAIDD items attach to the whole project, a whole stage (Task ID = the stage's last task + "[Stage stage]" prefix in the description) or one task.
