How this app works

This page runs entirely in your browser. It does not connect to the internet or to any server. It opens the SG&A tracker .xlsx, lets you edit the 5 input sheets (Projects, Activities, Benefits, Realisation, RAIDD) and writes your changes straight back into the same workbook. It only changes the input cells you edited, so formulas, tables, charts and formatting stay exactly as they were.

Recommended set-up with SharePoint (no third party)

  1. In SharePoint, open the document library and click Sync (or "Add shortcut to My files") so the workbook appears in File Explorer through OneDrive.
  2. Open this HTML in Microsoft Edge or Google Chrome and click Open workbook…. Pick the synced file.
  3. Make your changes and click Save to Excel. The file is overwritten in place, and OneDrive uploads it to SharePoint automatically.
  4. Other browsers (Firefox, Safari) download an updated copy instead. Upload it to SharePoint with the same name to replace the old one.

If a save does not reach SharePoint, or "goes back" to an old version

  1. Open the right file. Only a file in your OneDrive-synced folder reaches SharePoint (in File Explorer: your organisation → the SharePoint library, created with Sync or Add shortcut to My files). Files opened from the SharePoint website, Downloads, Teams or e-mail are local copies — saving them changes only the copy.
  2. Close the workbook in Excel (desktop and Excel for the web) before saving here. With AutoSave on, Excel writes its own copy back and your save "reverts".
  3. Wait for OneDrive's green tick on the file before opening it here, and after saving. If OneDrive shows a conflict, it keeps both files (one with your PC name) — keep the newer one.
  4. The app now checks the file again after saving (header shows ✓ saved & verified). If the file was replaced it warns you and offers Merge & save again, which reloads the current file and re-applies your changes so nobody's edits are lost.
  5. If the SharePoint library requires check-out, check the file out first (or ask the site owner to turn that setting off for this library).

Important

  • Close the workbook in Excel before saving from here, and make sure nobody else is editing it. Otherwise OneDrive may create a conflict copy.
  • Calculated fields (status, completion, IDs, forecast dates, Gantt dates, value totals) come from the last Excel calculation. The app tells Excel to recalculate everything when the file is next opened. Open it once in Excel (desktop or web) after saving; when Excel saves it, the new values show here.
  • New Projects, Tasks and Benefits get their ID straight away. The app writes it into the ID Lock (saved ID) column, so you can link RAIDD items and actuals before Excel recalculates.
  • The app checks whether the file changed on disk since you opened it and warns you before overwriting.

Each project page lists its linked steps with Open in flow and Link to steps…. Saved to the E2E_Flows and E2E_Map sheets.
